B.Tech Final Year Project: Hydrological Parameter Estimation & Flood Prediction

This project calculates AMDP and PMP values from historical meteorological data. It also includes an LSTM model for future flood prediction and a CNN model for weather image classification.

Developed using Open-Meteo API and research methods from Sarkar & Maity (2020).

Location & Period Details
Note on PMP: We are using the Extreme Value Analysis (EVA) method based on Sarkar & Maity (2020) for conservative calculation. PMP is dependent on the full dataset of the location.
